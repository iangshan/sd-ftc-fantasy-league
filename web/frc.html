2027 season. Priced using 2026 REBUILT. Draft one to three teams from the San Diego Regional field with 15 Pollen. Pollen is a free game resource.

Initial prices use each team’s average foul-adjusted qualification OPR across the selected 2026 REBUILT events. Those historical results set the prices; they do not count as 2027 points.

How scoring and prices work

For each counted 2027 event, we estimate a team’s scoring contribution from qualification matches after subtracting points awarded for opponents’ fouls. Your roster earns the sum of its teams’ finalized event OPRs. Awards, wins, and advancement add no separate points.

All six robots in each match are included when calculating OPR, including teams outside the draft pool. OPR is an estimate of contribution, not a directly measured individual score.

Prices are whole numbers from 3 to 11 Pollen, proportional to historical OPR. Teams without measured history receive a provisional price of 3. Prices are frozen when the first roster is saved.

FRC games change each year. A 2026 OPR is not a prediction of the number of points a robot will score in 2027.

Connect The Blue Alliance
  1. Create a free read API key in your TBA account.
  2. In Cloudflare, open sd-ftc-fantasy-staging → Settings → Variables and Secrets.
  3. Add a Secret named TBA_AUTH_KEY, paste the key there, and deploy the settings change.
  4. Return here, refresh the page, and import the data.

The key stays on the server. Do not put it in GitHub files or invitation links.

Automatic refresh runs every five minutes when a key is connected. A failed refresh retains the last successful data.

Test drafting

Staging rosters are separate from public league entries. Test drafting closes when a counted event starts.

Event choices

Event choices lock once any roster is saved. Changing them beforehand closes test drafting and requires a fresh import.
